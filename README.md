# Локальный медицинский ИИ-навигатор

Непубличный локальный медицинский ИИ-ассистент для личного и семейного использования в РФ.
Проект помогает структурировать данные о здоровье, разбирать анализы, отслеживать тренды и готовиться к визитам к врачу.

Ассистент не заменяет очного врача, не предназначен для экстренной помощи и даёт только информационную поддержку.
Ориентировочные диагнозы, гипотезы и примерные курсы лечения должны проверяться медицинским специалистом.

## Быстрый старт
### Backend
1. Создайте виртуальное окружение:
   ```bash
   cd backend
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Установите зависимости:
   ```bash
   python -m pip install -e ".[dev]"
   ```
3. Запустите API:
   ```bash
   uvicorn app.main:app --reload
   ```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Docker
```bash
docker compose up --build
```

## Что внутри
- `README.md` — главная документация проекта.
- `.gitignore` — исключения для секретов, кэшей, зависимостей и артефактов сборки.
- `.cursorignore` — исключает локальные секреты из контекста Cursor.
- `.cursorrules` — базовые правила для работы агента.
- `backend/` — FastAPI API, SQLite-хранилище, маршрутизация к LLM-провайдерам.
- `frontend/` — React + Vite интерфейс.
- `docker-compose.yml` — локальный запуск backend и frontend.

## Переменные окружения
Локальный `.env` не хранится в репозитории и не попадает в контекст Cursor.
Секреты храните только в `.env`; приложение читает значения через переменные окружения.

Шаблон: скопируйте `.env.example` в `.env` и заполните ключи API.

```bash
cp .env.example .env
```

Минимальные переменные для backend — см. `.env.example`.

## Маршрутизация моделей
| Задача | Переменная | Модель по умолчанию | Провайдер |
| --- | --- | --- | --- |
| Чат и triage | `SYMPTOMS_MODEL` | `qwen3.5-plus-02-15` | aitunnel.ru |
| Препараты и взаимодействия | `MEDICATIONS_MODEL` | `claude-sonnet-4.6` | aitunnel.ru |
| Нутрициолог и меню | `NUTRITION_MODEL` | `claude-sonnet-4.6` | aitunnel.ru |
| Сложные симптомы | `COMPLEX_SYMPTOMS_MODEL` | `deepseek-r1-0528` | aitunnel.ru |
| Углублённый разбор | `REVIEW_MODEL` | `claude-opus-4-7` | aitunnel.ru |
| Изображения и OCR | `IMAGING_MODEL` | `gpt-4o-mini` | proxyapi.ru |

Сложные обращения выбираются автоматически по эвристике (длинный текст, несколько симптомов, хронические заболевания) или вручную через чекбокс в интерфейсе. Сравнение мнений в истории обращений использует `REVIEW_MODEL`. Если в профиле указаны препараты, после основного анализа дополнительно вызывается `MEDICATIONS_MODEL`.

## Семейные профили

При первом запуске создаётся администратор:

- **Логин:** `admin`
- **Пароль:** `admin`

Обычные пользователи входят по своему имени и паролю. Администратор после входа может выбрать любой семейный профиль в выпадающем списке в верхней панели и добавить новых пользователей на странице входа.

API:
- `POST /api/auth/login` — вход
- `GET /api/auth/me` — текущая сессия
- `GET /api/auth/users` — список пользователей (admin)
- `POST /api/auth/users` — создать пользователя (admin)

## Сценарий «два мнения»

1. **Шаг 1 — чат «Новое обращение»** — ассистент собирает анамнез и даёт **первое мнение** (диагноз, план лечения) **до** визита к врачу.
2. **Шаг 2 — визит к врачу** — вы получаете **второе мнение** от очного специалиста.
3. **Шаг 3 — история обращений** — вводите мнение врача и нажимаете «Сравнить мнения»; ассистент показывает блоки: итог, совпадения, расхождения, рекомендации, вопросы врачу.

API:
- `POST /api/consultations/chat` — диалог и первое мнение
- `POST /api/complaints/{id}/compare-opinions` — сравнение с мнением врача

## Модели
- Симптомы и ориентировочные гипотезы: `Qwen3.5 Plus 02 15` через `aitunnel.ru`.
- Препараты и лекарственные вопросы: `Claude Sonnet 4.6` через `aitunnel.ru`.
- Сложные симптомы: `DeepSeek R1 0528` через `aitunnel.ru`.
- Углублённый разбор: `Claude Opus 4.7` через `aitunnel.ru`.

## MVP
- Первичное анкетирование: возраст, пол, рост, вес, жалобы, анамнез, аллергии, препараты, семейная история.
- Локальное хранение медицинского профиля в SQLite.
- Ввод лабораторных показателей и сравнение с предыдущими значениями.
- Загрузка PDF/текста/изображений как документов для будущего разбора.
- Маршрутизация моделей: симптомы, препараты, сложные случаи, углублённый разбор, изображения.
- Многошаговый чат: первое мнение ассистента и сравнение с мнением врача.
